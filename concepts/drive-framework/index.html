DRIVE framework

Definition

DRIVE is a framework and taxonomy for examining how students direct a generative AI interaction and express their expertise within it.

Explanation

Oliveira and colleagues describe “Directive Reasoning Interaction” and “Visible Expertise.” The framework distinguishes how a student steers the exchange from the domain knowledge made visible in the dialogue.

The original study analyzed 1,450 interaction annotations associated with 70 essays in STEM writing-intensive courses. It examined relationships between interaction quality and essay scores. The AIED assignment-perturbation study applied the framework to a different setting: discrete mathematics chatbot conversations.

That application should be identified as an application. Coding a conversation can organize evidence, but a code alone does not establish how much a student learned.

Scope and evidence

The framework originates with Oliveira and colleagues. Use the original framework’s name and attribution when citing this work.

Sources
