Concept

Three-Attempt Consistency Protocol

The Three-Attempt Consistency Protocol re-prompts a model with the exact query two further times, and classifies a question resistant only if all three attempts fail.

Also written: three-attempt protocol · result validity check

Defined in
Adversarial Assignment Perturbation: Effects on Help-Seeking Behaviors in Student Generative AI Chatbot Use, Table 1, step 8
DOI
https://doi.org/10.1007/978-3-032-29770-9_48
Tool
Perturbation Workbench

Ask a chatbot the same question twice and you can get two different answers. So a question it fluffs once it may well answer on the next try, and one failure tells you very little.

So after the first failure the model is re-prompted with the exact query two more times. Only if it fails across all three trials is the prompt classified as GenAI resistant. If a later attempt passes, that’s a false negative caught, and the record keeps it.
