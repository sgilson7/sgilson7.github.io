Concept

Three-Attempt Consistency Protocol

The Three-Attempt Consistency Protocol re-prompts a model with the exact query two further times, and classifies a question resistant only if all three attempts fail.

Also written: three-attempt protocol · result validity check

Defined in
Adversarial Assignment Perturbation: Effects on Help-Seeking Behaviors in Student Generative AI Chatbot Use, Table 1, step 8
DOI
https://doi.org/10.1007/978-3-032-29770-9_48
Tool
Perturbation Workbench

The protocol exists to mitigate false negatives. A model that fails a question once may pass the same question on a different roll, and a single failure is not evidence that a question resists anything.

So after the first failure the model is re-prompted with the exact query two more times. Only if it fails across all three trials is the prompt classified as GenAI resistant. A later attempt that passes is a false negative caught, and the record says so rather than quietly discarding it.
