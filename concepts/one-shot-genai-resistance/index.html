Concept

One-Shot GenAI Resistance

One-Shot GenAI Resistance is a property of an assignment question: a target chatbot scores below 60% on it across three separate attempts with the same prompt.

A property defined and operationalised in one AIED 2026 paper, on discrete mathematics questions tested against one named chatbot.

Sixty percent is where a student in the United States typically stops receiving course credit, which is where the threshold comes from. A question that holds a chatbot below it is a question a student cannot outsource and still pass.

Resistance is a property of a question against one named model at one point in time. The AIED 2026 study tested against Google Gemini 2.0-flash, the free tier available to students through the university during Summer 2025. A later model may solve the same question, which is why the protocol records which model it was run against.

One failure is not enough to classify a question. A model that fails once may pass on a second attempt, so the classification requires three failures of the exact same query against fresh instances.

Nearby terms in the literature: AI-resistant assessment, assessment security, cheating-resistant assignment design. None of these is a synonym for One-Shot GenAI Resistance; they name related work this paper did not measure against.

Related terms

  • iterative perturbation process

    The iterative perturbation process is an eight-step, instructor-led loop that rewrites an assignment question until a target chatbot fails it three times running.

  • Spatial Injection

    Spatial Injection is a perturbation strategy that adds reasoning requiring visual or geometric interpretation to a question, so a model must track layout as well as arithmetic.

  • Axiomatic Replacement

    Axiomatic Replacement is a perturbation strategy that alters a question's fundamental logical premises or axioms to prevent a model retrieving a memorised proof.

  • Contextual Embedding

    Contextual Embedding is a perturbation strategy that places a question inside unfamiliar, class-specific context which the grading rubric then requires the answer to use.

  • Three-Attempt Consistency Protocol

    The Three-Attempt Consistency Protocol re-prompts a model with the exact query two further times, and classifies a question resistant only if all three attempts fail.

  • Cognitive Scaffolding

    Cognitive Scaffolding is an engagement pattern in which a student recognises that a chatbot has hallucinated and supplies context to steer it toward a correct answer.

  • GenAI dependence

    GenAI dependence is an engagement pattern in which a student accepts a chatbot's hallucinated answer without critically evaluating it.

  • DRIVE framework

    The DRIVE framework is a taxonomy for generative AI interactions that separates how a student steers an exchange from how they articulate what they know.

  • AI Literacy

    AI Literacy is the set of competencies that let a person critically evaluate AI technologies, and communicate and collaborate effectively with AI.
