Every concept

Designing the assignment

  • One-Shot GenAI Resistance

    One-Shot GenAI Resistance is a property of an assignment question: a target chatbot scores below 60% on it across three separate attempts with the same prompt.

    Given an assignment question and a chatbot the class can actually reach, you can decide whether the question is resistant by testing it three times against the 60% threshold.

    Also written: One-Shot Generative AI Resistance · One-Shot GenAI-Resistant · One-Shot GenAI Resistant · AI-resistant assignment
  • iterative perturbation process

    The iterative perturbation process is an eight-step, instructor-led loop that rewrites an assignment question until a target chatbot fails it three times running.

    Given a question the chatbot already answers well, you can run the eight-step loop until it fails, choosing a perturbation each pass.

    Also written: Adversarial Iterative Perturbation · Adversarial Assignment Perturbation · iterative perturbation method
  • Spatial Injection

    Spatial Injection is a perturbation strategy that adds reasoning requiring visual or geometric interpretation to a question, so a model must track layout as well as arithmetic.

    Given a question whose reasoning is purely symbolic, you can add a visual or geometric constraint the model has to track.

    Also written: spatial constraint
  • Axiomatic Replacement

    Axiomatic Replacement is a perturbation strategy that alters a question's fundamental logical premises or axioms to prevent a model retrieving a memorised proof.

    Given a question answerable by reciting a standard proof, you can replace the axioms with an unfamiliar system of the same structure.

    Also written: axiom replacement
  • Contextual Embedding

    Contextual Embedding is a perturbation strategy that places a question inside unfamiliar, class-specific context which the grading rubric then requires the answer to use.

    Given a question stated in general terms, you can embed it in class-specific context the rubric requires the answer to use.

    Also written: contextual embedding strategy
  • Three-Attempt Consistency Protocol

    The Three-Attempt Consistency Protocol re-prompts a model with the exact query two further times, and classifies a question resistant only if all three attempts fail.

    Given a chatbot that has failed a question once, you can re-prompt twice with the exact query and classify only on three failures.

    Also written: three-attempt protocol · result validity check

Reading the transcript

  • Cognitive Scaffolding

    Cognitive Scaffolding is an engagement pattern in which a student recognises that a chatbot has hallucinated and supplies context to steer it toward a correct answer.

    Given a student's chat transcript on a perturbed assignment, you can identify where the student caught the model and steered it to a correct answer.

    Also written: cognitive scaffolding strategy · collaborative repair
  • GenAI dependence

    GenAI dependence is an engagement pattern in which a student accepts a chatbot's hallucinated answer without critically evaluating it.

    Given a student's chat transcript on a perturbed assignment, you can identify where the student accepted output without evaluating it.

    Also written: Dependency · Dependence · cognitive outsourcing
  • DRIVE framework

    The DRIVE framework is a taxonomy for generative AI interactions that separates how a student steers an exchange from how they articulate what they know.

    Given a query-response pair from a student-chatbot transcript, you can tag it on directive reasoning and visible expertise.

    Also written: Deep Reasoning in Virtual Education · DRIVE taxonomy

Why students study outside class

  • online, on-demand CS coursework

    Online, on-demand CS coursework is computing coursework a student takes outside a degree programme, on their own schedule, to supplement that programme.

    Given a student's account of studying outside their degree programme, you can recognise it as online, on-demand CS coursework and ask what made them start and stop.

    Also written: OOD CS coursework · OODCS · on-demand computer science coursework

Checking the chatbot's work

  • Hallucination Autopsy Procedure

    The Hallucination Autopsy Procedure is a seven-step routine for finding where a chatbot's proof leaves the claim it was given, and naming why it left.

    Given a chatbot's written proof of a claim you can state exactly, you can find the first line where it diverges, classify the failure, and say why that failure was likely.

    Also written: hallucination autopsy · Procedure A
  • Axiom Reversion

    Axiom Reversion is a failure mode in which a chatbot swaps in the textbook theorem that the problem was perturbed away from.

    Given a chatbot proof whose closed form you can compare against the problem, you can check whether the closed form matches the textbook rather than the problem in front of you.

    Also written: axiom reversion failure
  • Invalid Syntactic Shortcut

    An Invalid Syntactic Shortcut is a failure mode in which a chatbot manipulates a form as though a rule applied, producing a step that is well-formed and false.

    Given a chatbot proof step that looks algebraically ordinary, you can check the step symbolically, because it is written to look like a rule being applied.

    Also written: syntactic shortcut
  • Spatial or Counting Miscount

    A Spatial or Counting Miscount is a failure mode in which a chatbot counts placements that break the constraint, or counts the same one twice.

    Given a chatbot's answer to a counting or placement problem, you can add the case breakdown up and see whether it reaches the total it claims.

    Also written: counting miscount · spatial miscount

Writing the prompt

  • Strong Prompt Structure

    Strong Prompt Structure is a four-part shape for a prompt: establish context, require justification at every step, build in self-questioning, and plan the correction.

    Given a question you are about to hand to a chatbot, you can write the context, the justification requirement, the self-check and your correction before you send it.

    Also written: Procedure B · structure of a strong prompt
  • Collaborative Prompting

    Collaborative Prompting is a six-step routine in which a student forbids the final answer, takes one step at a time, and checks each against cases computed by hand.

    Given a problem you want to work through with a chatbot rather than hand to it, you can withhold the answer, elicit one justified step at a time, and decide disputes with small cases you computed yourself.

    Also written: Procedure C · scaffolding strong prompts

Building with an agent

  • GenAI-Assisted Prototyping Procedure

    The GenAI-Assisted Prototyping Procedure is a nine-stage pipeline, brief to handoff, in which a person reads the plan, plays the build, and deploys it.

    Given a software artefact you intend to build with a coding agent, you can write the brief, read the plan before any code, keep the notebook, play the build, and deploy it yourself.

    Also written: GenAI-assisted prototyping · agentic prototyping procedure

How the instruction is built

  • Subgoal Label

    A Subgoal Label names the function a step serves in any problem of its type, so a learner can separate a solution's structure from one example's surface details.

    Given a worked example whose steps you want a student to reuse on a different problem, you can name what each step is for, and use the same name in the reference box, the worked example and the student's own task.

    Also written: subgoal labelling · subgoal-labeled instruction
  • AI Literacy

    AI Literacy is the set of competencies that let a person critically evaluate AI technologies, and communicate and collaborate effectively with AI.

    Given a student who will use a chatbot on coursework whether or not you teach them to, you can teach appraising the output and questioning the system, not only operating the tool.

    Also written: artificial intelligence literacy

Where this comes from

I built this way of writing a subject down for curriculum work — every idea as a thing you can do, every connection as a sentence, and a hard rule that if you cannot write the sentence then you do not have a connection. It rests on the knowledge-learning-instruction framework of Koedinger, Corbett and Perfetti, and it is written up in Building and Analysing a Knowledge-Component Graph for a Course Unit (September 2026). Here it is pointed at my own vocabulary instead of a course.

A word on what the arrows are. In a course, an arrow carries a weight: how many graded questions make a student use both ends of it, which is how you find the connections a course states and never exercises. These arrows carry no weight, because there is no homework behind them. They record how the ideas depend on one another, which is a weaker claim than a course graph makes.
