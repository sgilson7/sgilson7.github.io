Free-tier accessible model

Definition

A free-tier accessible model is a model available through an access route that does not require a paid subscription at the time of use.

Explanation

Access is part of the study setting. A model tested through an API is not automatically the same experience a student receives through a free consumer account. Routing, limits, tools, and model versions can differ.

A useful record therefore names the product, displayed model, access tier, date, and relevant settings. “Free” should describe that record, rather than imply permanent availability or identical access for every student.

The manuscript under review considers free-tier access in relation to mathematical capability evidence and AI literacy instruction.

Scope and evidence

This is an access condition, not an established measure of learning. The manuscript’s detailed results are not reported here because a public text is not available.
