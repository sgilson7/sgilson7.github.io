Concept

Contextual Embedding

Contextual Embedding is a perturbation strategy that places a question inside unfamiliar, class-specific context which the grading rubric then requires the answer to use.

Also written: contextual embedding strategy

Defined in
Adversarial Assignment Perturbation: Effects on Help-Seeking Behaviors in Student Generative AI Chatbot Use, Table 1, step 5, and Q3
DOI
https://doi.org/10.1007/978-3-032-29770-9_48
Tool
Perturbation Workbench

The worked example takes a single-quantifier syllogism and expands it into a multi-variate system with three existential quantifiers.

The failure it produces is a specific and useful one: the model frequently reached correct semantic conclusions through invalid syntactic shortcuts. The rubric penalises exactly that, by demanding an explicit citation of the rule of inference at every step — so an answer that arrives in the right place by the wrong route does not score.
