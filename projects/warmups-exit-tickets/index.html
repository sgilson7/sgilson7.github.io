Warm-ups and Exit Tickets

Classroom tool

The teacher chooses one or more source documents and a Depth of Knowledge level from 1 to 4, and the tool builds a warm-up of three questions or an exit ticket of two from a question bank written in advance. Any question can be swapped for another drawn from the same sources at the same level. The set can be printed or saved as a text file. A student opens the same page on their own device, types the set code or opens the saved file, answers, and sees which answers match the key.

Everything is computed in the browser on the device that opens the page. The page sets a Content-Security-Policy whose connect-src is 'self' and whose form-action is 'none', so the page has no route to another origin.

The question bank the tool ships with is sample content: three sources across four Depth of Knowledge levels, two questions each, on fractions. It is there to show how the tool works. Write or load a bank of your own before using it with a class.

Using the tool

Pick the sources and the level, choose a warm-up or an exit ticket, swap any question you would rather not use, and print or save the set.
