Gear Master

Build gear out of parts, then watch your character auto-battle. Rust + macroquad.

Written in
Rust
Run it
https://sgilson7.github.io/gear-master/
Source
https://github.com/sgilson7/gear-master

An auto-battler where the whole of your input is how you pack components into grids. Components form items when their shapes touch and satisfy a recipe; items activate on cooldowns, and the fight runs itself.

Written in Rust with macroquad, with the engine in a core crate that has no browser dependencies, so the rules run under cargo test without a browser.
