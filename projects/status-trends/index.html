Status Trends

Classroom tool

Status Trends turns a CSV export into a dashboard. A project manager opens an export from Jira or another tracker; a teacher opens one row per student per assignment from a gradebook. The page counts the items received each year, quarter or month, split by where they stand today (still requested, pending or completed), and shows the percentage change on the period before and on the same period a year before, on the charts and in the table. It also shows completion against a target, the open backlog at the end of each period, and the median days to complete.

A list of insights and risks applies rules to the same numbers: completion below the target, completion falling three periods running, more items received than completed three periods running, items open too long, items past due, jumps in volume, slower completion, and teams or students below the target over the last year. The thresholds can be changed in the page, and so can every guess about which column holds which date and which status counts as done. The year can start in any month.

The file is read with the browser's own file reader and analysed in the tab by a WebAssembly module. The page fetches every file it needs before it reports ready, and a browser check in Chromium, Firefox and WebKit fails on any request after that point, to this site or any other, and on anything left in cookies or browser storage, while a file is opened and the dashboard is used. A second script plants five kinds of leak in a copy of the tool and requires the checks to catch each one. The page sets a Content-Security-Policy whose connect-src is 'self' and whose form-action is 'none'. Opening the page, turning off Wi-Fi and then opening a file is a test anyone can run.

Two samples show the tool: a set of invented team requests over four years, and an invented class over one school year. The tool was built from the Builder template, and the repository holds its brief, plan, notebook and checks.

Using the tool

In Jira, search for the issues you report on and choose Export, then Export CSV. Open the file in the page, or drop it on the page. Check the guesses under "Columns, statuses and thresholds", choose year, quarter or month, and save the table as CSV or print the page as a PDF for a report.
