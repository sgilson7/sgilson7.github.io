Tools and games

Research tools

Built for the studies, and released so somebody else can run the same protocol. Both run entirely in the browser: no server, no account, and no network request after the page loads.

  • Perturbation Workbench

    Run the AIED 2026 iterative perturbation protocol in the browser. Nothing is uploaded.

    RustOpen the tool Source
  • PDF Redactor

    Redact student names and strip all metadata from PDFs, entirely in your browser. Nothing is uploaded.

    RustOpen the tool Source

Games

Not research. Listed because they are public work, and because the engine discipline is the same one the research tools use: the rules live in a core crate with no browser dependencies, so they are testable without one.

  • Gear Master

    Build gear out of parts, then watch your character auto-battle. Rust + macroquad.

    RustPlay Source
  • Gear Master 2D

    A 2D tile-based open-world RPG on the gear-assembly auto-battler from gear-master.

    RustPlay Source
  • Floodline

    Multiplayer medieval city builder in the browser. Deterministic lockstep over WebRTC; every age ends in a flood.

    RustPlay Source
