Gear Master 2D

A 2D tile-based open-world RPG on the gear-assembly auto-battler from gear-master.

Written in
Rust
Run it
https://sgilson7.github.io/gear-master-2d/
Source
https://github.com/sgilson7/gear-master-2d

The auto-battler from Gear Master, put inside a tile-based open world. You walk a map, meet creatures and fight them — but you do not fight: you pack five grids with components, and the arrangement is the whole of your input.

The engine keeps the same discipline: the core crate never imports anything DOM-shaped, so the whole rule set is testable in seconds, and the browser shim decides nothing.
