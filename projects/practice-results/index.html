Practice Results

Classroom tool

Practice Results has two views. A student practises a set of multiple-choice questions on their own device, checks their answers to see a score for each topic, and saves a result file under a nickname they choose; there is no name and no account. A teacher opens all the result files at once and sees, for each topic, the share of correct answers, the questions missed most often, and a suggestion to reteach any topic that falls below a threshold the teacher sets, which starts at 70%.

Everything is computed in the browser on the device that opens the page. The page sets a Content-Security-Policy whose connect-src is 'self' and whose form-action is 'none', so the page has no route to another origin.

The practice set the tool ships with is sample content: twelve ratio questions across four topics, written to exercise the tool rather than to be taught. Check it or replace it before using it with a class.

Using the tool

Open the student view, work through the questions, and save the result file. In the teacher view, open the files the students handed in and set the threshold below which a topic is flagged for reteaching.
