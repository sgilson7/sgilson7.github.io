Research tool

PDF Redactor

Redact student names and strip all metadata from PDFs, entirely in your browser. Nothing is uploaded.

Written in
Rust
Run it
https://sgilson7.github.io/pdf-redactor/
Source
https://github.com/sgilson7/pdf-redactor

Built for the obligation that comes with studying student work: a corpus has to be de-identified before anybody else sees it, and you have to be able to show, months later, that it was.

It rebuilds the PDF from scratch rather than covering things up. Redaction boxes are painted into the page bitmap before it is encoded, so the covered pixels do not exist in the output — there is no black rectangle to delete and no earlier revision left in the file. Metadata goes the same way: the output contains only what the writer chose to emit.

The text layer survives. The original text is re-attached as invisible text after every span touching a redaction box has been dropped, so a redacted corpus is still searchable. Content streams are left uncompressed so you can check the tool’s work yourself.

Questions this page answers

  • How do I de-identify student PDFs for a study without uploading them anywhere?
  • How do I strip metadata from a PDF before sharing it with a collaborator?
