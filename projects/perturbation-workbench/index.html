Perturbation Workbench

Run the AIED 2026 iterative perturbation protocol in the browser. Nothing is uploaded.

Implements
Adversarial Assignment Perturbation: Effects on Help-Seeking Behaviors in Student Generative AI Chatbot Use

This is the tool for running the protocol from the AIED paper on your own assignment.

It walks you through Table 1 and produces two artefacts a collaborator at another institution can check: the assignment, and a run manifest that is a proof of execution.

You are the transport between the workbench and the chatbot. The tool has no API key and no code that could use one, so it hands you the exact query, you paste it into a fresh instance, you paste the response back, and you grade it against your rubric. What the tool guarantees is that the protocol was followed: the same bytes were prompted three times, the rubric was fixed before grading, and nothing was stamped resistant that did not earn it.

The manifest leaves the questions out, on purpose. It carries counts, ordinals, settings, hashes and timestamps, and there is no field through which question text could arrive. A record that leaked the questions it certifies would destroy the thing it was made to protect.
