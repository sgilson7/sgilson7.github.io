Feedback Drafts

Classroom tool

Feedback Drafts helps a teacher write individual feedback from their own rubric. The teacher picks a level for each criterion, can add the student's name and a personal note, and the tool writes a draft: an opening line, one paragraph per criterion with the comment the teacher wrote for that level, the points if the rubric shows them, the note, and a closing line. The teacher edits the draft, then copies it or saves it as a text file. The comments in a draft are the teacher's own, written once into the rubric, and the student's work never enters the tool.

The rubric can be edited in the page (criteria, level labels, points and comments) and saved as a file to open again. The tool answers a request teachers have made for feedback drafts they can inspect and revise before sharing. Drafting from the student's submission would need a language model while the teacher works; this tool keeps the editable draft and moves the writing into the rubric, so it runs as a static page.

Everything is computed in the browser on the device that opens the page, and the page uses no browser storage, so a name or note is gone when the page closes. The page sets a Content-Security-Policy whose connect-src is 'self' and whose form-action is 'none', so the page has no route to another origin.

The rubric the tool opens with is sample content: four criteria for a project report, written to show the tool rather than to be used as it stands. Check it or replace it before using the tool with a class. A fresh coding-agent session built the tool from the Builder template and a single prompt set, which is in the Builder repository.

Using the tool

Edit the sample rubric or open your own, and save it. For each student, pick a level for every criterion, add a name and a note if you want them, then edit the draft and copy it. Next student clears the name, the levels and the note and keeps the rubric.
