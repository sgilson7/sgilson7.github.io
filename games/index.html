Games

Browser games by Sam Gilson, written in Rust and made with Builder. Each game's tile opens the game straight away, and Read more describes it. The games that several people can play together are repeated under Multiplayer. Tools · All tools and games

Made with Builder

Builder is the template, agent instructions and check command these games were built with, and it keeps every rule of a game in a tested Rust core.

    A template, agent instructions and one check command for building small browser tools with a coding agent, with every rule in a tested Rust core.
