Using these tools in a school

This page is for a teacher, a school's IT staff or a district privacy reviewer deciding whether students may open one of the tools under Tools and games. For each tool it says what the page sends, what it keeps in the browser, what the device has to allow, and how that was checked.

What the tools have in common

Each tool is a static page that GitHub Pages serves from sgilson7.github.io. There is no account, no login and no server of mine behind any of them. Each tool page sets a Content-Security-Policy whose connect-src is 'self' and whose form-action is 'none', so the browser refuses a request from the page to another origin; the policy is in the page source for anyone to read.

GitHub logs the IP address of each visitor to a Pages site for security purposes, as GitHub's documentation states. That record is the host's. The tools themselves receive nothing.

The tools run their rules in WebAssembly. A Chrome policy that turns off JavaScript JIT (DefaultJavaScriptJitSetting) also turns off WebAssembly, and the student tools then show a message saying so. Where a tool saves or opens a file, Chrome's DownloadRestrictions and AllowFileSelectionDialogs policies can block that step, and the student tools say so beside the button.

Browser storage belongs to the whole of sgilson7.github.io, which also serves the games. The table says which tools keep anything in the browser. On a shared student device, prefer the tools that keep nothing.

Asking IT to allow a tool

A teacher can send this, with the tool's address filled in:

Please allow students to open https://sgilson7.github.io/TOOL/ during class. It is a static web page with no login and no account. Its Content-Security-Policy allows connections only to sgilson7.github.io, and what a student types or opens stays in their browser tab. It needs WebAssembly, and saving or opening files if the tool uses them. If the filter blocks github.io as a whole, an allow rule for the single host sgilson7.github.io is enough: github.io is on the Public Suffix List, so each user's host is its own site. What each tool sends and keeps is listed at https://sgilson7.github.io/schools/.
